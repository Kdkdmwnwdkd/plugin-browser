图标回来了，而且是同一套

2.10.1 把功能面板的图标全撤了，理由是那批图标一半实心、一半线框，染成同一个颜色之后
块状和线条混着排，越看越乱。撤完之后确实干净，代价是得逐行读字才知道哪个是哪个。

这次不是把旧图标放回去，是把它们换成同一套字形——Material Icons 的 filled 线，
统一 20dp、统一字重、统一视觉重心。四十二个图标一起换，连地址栏的刷新、
标签切换页的无痕标识也一起对齐了。

功能面板
- 每一行重新带上图标，左边图标、中间文字、右边状态。
- 分组和留白保持上一版：当前页 / 打开 / 工具 / 显示 / 更多，不画线。

新功能
- 二维码：把当前地址变成一个方块，加一行域名。深色模式下也是白底黑码——
  黑底白码有一半扫码器认不出来。
- 打印 / 存为 PDF：走系统打印面板，里面自带「另存为 PDF」。不再单独做一个导出按钮，
  两个入口做同一件事，用户还得猜哪个才是导 PDF 的。
- 清除跟踪参数：删掉 utm_*、gclid、fbclid、spm、share_token 这些只用来跨站认人的参数，
  然后重新加载。链接没脏就不动，只回一句「这个链接没有跟踪参数」。
- 添加到桌面：把当前页钉到桌面，点开直接进这一页。

WebDAV 备份
设置 → 备份 → WebDAV 备份。填服务器地址（到目录为止）、账号、密码、文件名，
就能把书签和历史整包传上去、整包拉回来。适配 Nextcloud / 坚果云 / 群晖这类标准实现。
失败时给的是人话：401 是账号密码不对，404 是路径不存在，507 是网盘满了。
密码只存在本机应用私有目录，而且导出备份时会把这个键排除掉——否则备份文件里带着
自己的密码，再传回同一个网盘，等于把钥匙挂在保险箱门上。

标签休眠
一个标签就是一个渲染进程，开着七八个页面，中低端机迟早被判内存不足、整个 App 被杀。
现在系统喊「内存见底」（TRIM_MEMORY_RUNNING_CRITICAL）时，后台标签的 WebView 会被销毁，
只留地址，切回来按原地址重建。当前标签和无痕标签不动。

顺带修了一个一直存在的问题：原来 onTrimMemory 写的是 level >= RUNNING_LOW，
而 UI_HIDDEN 是 20、比 10 大——切到后台也会走这条分支。降级无害，但把休眠挂上去
就会变成「退到桌面一次，所有标签全被收掉」。
